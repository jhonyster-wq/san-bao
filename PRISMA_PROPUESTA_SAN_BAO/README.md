3. **Exportación Final a PDF:**
   - Una vez reemplazados los marcadores `[PENDIENTE DE CONFIRMAR]` en los archivos `.docx` desde Microsoft Word o LibreOffice Writer, utilice `Archivo -> Guardar como -> PDF` para generar las copias inmutables de cierre junto con los archivos editables.
