2. Arquitectura de Software, Normalización PostgreSQL (3NF/BCNF) y Rendimiento

Capa Tecnológica Especificación de Producción Optimizaciones Implementadas
Base de Datos Relacional PostgreSQL 16 Alpine (3NF / BCNF) 10 esquemas lógicos (core, academic, clinical, finance, hr, ecommerce, lms, integrations, bi, audit), 78 tablas, 157 claves foráneas, 12 restricciones únicas compuestas y 292 índices B-Tree. Catálogos maestros 3NF para Centros de Costo y Unidades de Negocio.
Backend API FastAPI + Uvicorn ASGI (Python 3.10+) Compresión GZipMiddleware (reducción >85% en payload), pool de conexiones persistentes (pool_size=20, max_overflow=40, pool_pre_ping=True) y cabecera de telemetría X-Process-Time-Ms.
Frontend Web & Móvil SPA Responsiva (Desktop, Tablet Box, Móvil QR) Coalescing de iconos por requestAnimationFrame, caché GET con deduplicación de peticiones en vuelo, lazy-loading por portal activo y contención CSS.
Proxy Inverso & Seguridad Nginx Alpine + TLS 1.3 Certificados SSL Let's Encrypt / Cloudflare WAF Santiago, respaldos diarios automatizados pg_dump a las 03:00 AM.
